Before you start

Join the test first: follow Steps 1 and 2 on the Android tester page (join the tester group, then tap Become a tester). Use the same Google account for everything.

Option 1: Quick link

On your Android phone, open the link below and type in your code.

Redeem a code on Google Play

Option 2: In the Play Store app

  1. Open the Play Store app.
  2. Tap your profile picture in the top right.
  3. Tap Payments & subscriptions, then Redeem code.
  4. Type in your code and tap Redeem, then confirm.

Then install

Open Holdout in the Play Store. The button now says Install instead of a price.

Open Holdout in the Play Store app

If something doesn't work

  • "Item not found": you just became a tester. Wait up to an hour and try again.
  • Code not accepted: each code works once, on one account. Check for typos, and make sure the Play Store app uses the account you joined the test with.
  • Need help? Email thelastfleetgame@gmail.com.
