# Homepage concepts

Four candidate designs for the thelastfleet.com homepage. These pages are not linked from anywhere on the site; pick one and it becomes the new `index.html`.

| # | Name | Look |
|---|------|------|
| 1 | [Command](1-command/) | Closest to the reference: dark navy, electric-blue buttons, big game tiles |
| 2 | [Tactical](2-tactical/) | Military HUD: stencil type, amber on black, radar reticle, numbered fleet roster |
| 3 | [Cinematic](3-cinematic/) | Movie poster: giant stencil title over full-screen art, gold accents, game chapters |
| 4 | [Bento](4-bento/) | App-store modern: floating pill menu, glass tiles, every game in one grid |

Device mockups and full-page screenshots are in `previews/`.
